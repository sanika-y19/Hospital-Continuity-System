Hospital Continuity System

Overview

The Hospital Continuity System is a beginner-friendly Flask project that demonstrates how essential hospital operations can continue when the main data centre becomes unavailable.

Problem Statement

A data centre failure can interrupt access to important hospital information and affect daily operations. A continuity plan can help maintain access to essential services during such failures.

Features

- Simulated main data centre failure
- Backup server demonstration
- Patient records using fictional demo data
- Hospital status dashboard
- Flask-based web interface

Technologies Used

- Python
- Flask
- HTML
- Git and GitHub

How to Run

1. Install Python.

2. Install Flask:
   
   "pip install flask"

3. Run the application:
   
   "python hospital_continuity.py"

4. Open "http://127.0.0.1:5000" in your browser.

Important Note

This is an educational simulation using demo data. It does not provide real hospital infrastructure, production-grade failover, or secure medical-record storage.
